# 中南大学生工作台 · ZUEL Student Workstation

> 面向高校辅导员的**本机学生工作台**：把教务/学工系统导出的学生信息表 + 成绩单丢进来，
> 自动拼出每个人的画像、成绩、宿舍与学业预警。
>
> **数据只存本机，全程不联网、不上传服务器。**

📜 **完整版本历史见 [CHANGELOG.md](CHANGELOG.md)** —— 从原型阶段到 v1.9.5 的每一步都记在里面。

## 📥 下载使用（只想用软件，不想看代码）

到 [Releases](https://github.com/xpsmsn/zuel-student-workstation/releases) 页面，挑最新版本的一个下载：

| Assets 文件名 | 对应安装包 | 适合谁 |
| --- | --- | --- |
| `ZUEL-StudentWorkstation-v1.9.7-Portable.exe` | 绿色版 | 复制到任意文件夹双击就跑，**不用安装** |
| `ZUEL-StudentWorkstation-v1.9.7-Setup.exe` | 安装程序 | 日常使用，装到开始菜单/桌面，**不需要管理员权限** |
| `ZUEL-StudentWorkstation-v1.9.7-Deploy.msi` | 单位部署 | 学校统一部署（域策略下发），通常需管理员权限 |
| `ZUEL-StudentWorkstation-v1.9.5-macOS.dmg` | **macOS 版** | 苹果电脑用；Intel 与 Apple 芯片（M 系列）通用，**首次打开需右键 →「打开」**放行一次 |

四个文件里的程序完全一样，只是**平台与安装方式**不同。

> 文件名是英文的，是因为 GitHub 的 Release 附件不支持中文名（会被清成 `-.exe`），下载后建议改回中文名再分发。
> **文件名里都带版本号**（`v1.9.5`），拿到手就知道是哪一版，不会和旧版搞混。

**运行环境**

- **Windows**：Windows 10/11 64 位 + Microsoft Edge WebView2 运行时
  （Win11 与多数装过 Edge 的 Win10 已有，缺的安装器会自动引导安装）。
- **macOS**：macOS 10.15 及以上，Intel 与 Apple 芯片都可以；系统自带网页运行时，**不需要**额外安装东西。
- 两个平台都**不需要** Node.js / Rust / .NET —— 那些只在重新出包时才用得到。

详细操作见仓库内的 `中南大学生工作台-用户使用手册.docx`。

## ✨ 主要功能

- **导入**：学生信息表 + 成绩单，按列合并、按批次管理；支持三种导入模式（覆盖 / 追加 / 合并）
  - v1.9.2 起**表头不在第 1 行也能自动定位**（如「入党积极分子名册」表头在第 4 行），
    并自动剔掉"培养联系人 1|2"这类子表头行；报错行号指向原表真实行号
  - v1.9.2 起导入**积极分子名册会自动把匹配到学生的政治面貌同步为「入党积极分子」**，
    已是党员/预备党员/发展对象的不降级
- **总览**：人数、覆盖班级、需重点关注、不及格、加权成绩、绩点等指标卡 + 手写 SVG 图表，点图可下钻
- **列表**：筛选（班级/性别/政治面貌/宿舍，**v1.9.3 起为复选框面板，一次可勾多个值、勾完不用反复点开**）、
  表头排序、列自定义、详情页全字段编辑
- **关注视图**：挂科、绩点偏低、未录成绩、已写备注等预设筛选
- **宿舍看板**：按床位基准生成房间卡，空位/满员/超员一目了然；**v1.9 起可导出 A4 横向「查寝打分表」**
- **取数指引 + 新手向导**：v1.9 重做为 6 步实操向导，每步都有可点的按钮，跟着做一遍就能完成下载与导入
  - **向导结束后跟着浮出「页面浮窗批注」导览**（v1.9.4 起 **11 步**），逐块点出界面上每个位置是干什么的；
    v1.9.4 补上了**四个常用功能**（校务导航 / 常用模板 / AI 辅导员 / 校历作息）各一步。
    （可跳过、可重看；老用户升级不会被打扰）
- **AI 辅导员**：鹿晓南（制度流程）与 **综合评定答疑机器人**两个企业微信入口，
  **v1.9.3 起两人各占一张等宽卡片、二维码统一为 200×200 白底外框（去掉了背景，深色主题下也仍是白底可扫）**，
  每张码下面都有**「复制链接」**，一键粘进企业微信班级群；「关于」页里那份已删掉
- **备份恢复 / 导出 CSV / 导入历史**：随时回滚
- **桌面增强**：缩到托盘后台常驻、可选开机自启、导出文件落「下载」文件夹并自动打开
- **只开一个窗口**（v1.9.1）：已经在后台时再双击图标，会把原来那个叫回前台，不会开出第二个

## 🔒 数据在哪

桌面版数据存在 `%LOCALAPPDATA%\cn.edu.zuel.studentworkstation\...` 的 Local Storage 里
（存储键 `counselor_workstation_v2`）。卸载程序**不会**删数据（有意为之，防误删）。

每次保存还会**同时镜像一份到** `%APPDATA%\cn.edu.zuel.studentworkstation\workstation-data.json`，
所以清理浏览器缓存、重置 WebView、重装程序之后，下次打开会自动从这里恢复。
换机或备份走「系统设置 → 数据管理 → 导出完整备份」，也可以直接拷走那个 json 文件。

⚠️ 桌面版与用浏览器打开 `中南大学生工作台.html` 的数据是**两份、互不通用**。

# 🏫 其他学校：怎么把它改成"我们学校的工作台"

这一节写给**没有开发基础**的老师。先给结论：

> **要改的东西不多，而且你不必自己写代码。**

> ⚠️ **先说清楚校名**：本项目里的「中南大」指的是 **中南财经政法大学**（英文缩写 **ZUEL**），
> **不是中南大学**。下面说的"换成你们学校"，指的是把**全称 / 简称 / 英文缩写**这三套说法一起换掉。

### 为什么说这件事不难

这个项目的构造很特别，整个软件只有两个"肉"：

| 部分 | 是什么 | 你要不要动 |
| --- | --- | --- |
| `中南大学生工作台.html` | 一个 1 MB 出头的 HTML 文件，**界面和业务逻辑全在里面**。没有框架、不用编译，双击就能在浏览器里打开 | ✅ 主要改这里（改文字、改地址、改表头映射） |
| `app/` | 一个很薄的 Windows 桌面壳，只负责三件网页做不到的事：导出文件落盘、外链用系统浏览器打开、缩到系统托盘 | ⚠️ 基本不用动，只改校名和图标 |

所以"换成我们学校"，90% 的工作是**改文字和网址**，不是写程序。

### 推荐工具：用 WorkBuddy 来改，而不是手改

建议直接用 [WorkBuddy](https://www.workbuddy.cn/)（一个能读你整个项目、按你的话改文件的 AI 助手）来做这件事。理由说人话就是三条：

1. **那个 HTML 太大了，人肉改会漏。** 一百多万字，光"中南大学生工作台"这个产品名就散落在几十处，还夹杂着"中南大""ZUEL"各种缩写。手工替换一定会有漏网之鱼，最后软件里一半是你校名一半是别人校名。交给工具整篇扫一遍最稳。
2. **改完能立刻自检。** 仓库里已经写好了 128 条自动检查（`.build/test-library.js`），工具改完能自己跑一遍，哪里改坏了会当场告诉你，不用等老师用的时候才发现。
3. **你说话就行，不用学代码。** 用大白话提要求，它自己去找对应的地方改。

> 如果你更习惯自己动手，下面每一步也都写了具体改哪个文件、改哪个位置，照着做同样可以。

### 第 1 步：把项目弄到自己电脑上

两种办法选一个：

- **会用 Git**：
  ```bash
  git clone https://github.com/xpsmsn/zuel-student-workstation.git
  ```
- **不会用 Git**：去 [Releases](https://github.com/xpsmsn/zuel-student-workstation/releases) 页面最下面，下载 **Source code (zip)**，解压到任意文件夹。

### 第 2 步：用 WorkBuddy 打开这个文件夹，照着下面说话

把下面这些话**一行不改地复制过去**（把尖括号里的内容换成你们学校的），一条一条来：

**① 先改校名和品牌（一次性改干净）**

```
打开这个项目，把学校标识整体换成我们学校的（三套说法一起换，别只换一套）：
  - 全称：「中南财经政法大学」→「XX大学」
  - 简称：「中南大」→「XX大」；英文缩写：「ZUEL」→「XXU」
  - 产品名：「中南大学生工作台」→「XX大学生工作台」
包括：页面上的产品名、浏览器标签页标题、登录页、顶部金句库里带校名的句子，
以及 app/src-tauri/tauri.conf.json 里的 productName 和 publisher。
改完告诉我一共改了多少处、分别在哪几个文件。
```

**② 换成你们学校的系统地址**

```
把「取数·导入指引」里两个系统的地址换成我们学校的：
智慧学工：https://xxx
综合教务：https://yyy
（原型里搜索 ZUEL_SYS，把里面的 url 改成这两个，名字也一起改）
```

**③ 适配你们学校导出的表格（这一步最关键，也最值得让工具做）**

```
我们学校导出的学生信息表，第一行表头是这些：
<把 Excel 第一行复制粘贴到这里>

成绩单的表头是这些：
<把 Excel 第一行复制粘贴到这里>

请照着原型里「字段别名表」的写法，把我们学校的表头映射进去。
映射完跑一下 node .build/test-library.js，确认没有把别的功能改坏。
```

**④ 换成你们的校徽**

```
用这张校徽图 <把图片文件拖进对话> 重新生成全套桌面图标，
替换 app/src-tauri/icons 下所有文件。
命令是：python .build/make-icons.py <图片路径> app/src-tauri/icons
```

**⑤ 出安装包**

```
帮我重新出安装包，版本号改成 vX.Y.Z，
按 .build/pack-release.py 的命名规则把三个产物放进「发布」目录，
并同步更新安装说明和 README 里的文件名。
```

### 第 3 步：验收（改完一定要做）

```bash
node .build/check-syntax.js 中南大学生工作台.html   # 语法有没有写坏
node .build/test-library.js                          # 128 条功能断言
node .build/test-delete-backup.js                    # 备份/覆盖导入
node .build/test-desktop.js app/src/index.html       # 桌面适配层 28 条
```

全部通过再发出去。另外建议自己照着软件里的「新手引导」完整点一遍：
导入两份表 → 看总览 → 看宿舍看板 → 导出一次查寝打分表。

### ⚠️ 三个地方千万别乱动

| 东西 | 为什么 | 怎么做 |
| --- | --- | --- |
| `identifier`（`cn.edu.zuel.studentworkstation`） | 它决定数据存在电脑的哪个文件夹。**已经开始给老师用之后再改，所有人电脑上的数据会"找不到"，等同于丢失** | 新学校**一开始就换成自己的**（比如 `cn.edu.你们学校域名.studentworkstation`），之后永远不再动 |
| 存储键 `counselor_workstation_v2` | 同上，是数据在浏览器里的名字 | 别改 |
| `app/src/index.html` | 它是**自动生成**的，每次出包都会被覆盖 | 要改就改项目根目录那个 `中南大学生工作台.html` |

### 只想最小改动？改这 4 处就能用

| # | 改什么 | 在哪 |
| --- | --- | --- |
| 1 | 校名 / 产品名 | 原型 HTML 全文 + `app/src-tauri/tauri.conf.json` 的 `productName` |
| 2 | `identifier` | `app/src-tauri/tauri.conf.json`（**只在新项目开始时改一次**） |
| 3 | 两个校务系统地址 | 原型 HTML 里搜 `ZUEL_SYS` |
| 4 | 导出表格的表头映射 | 原型 HTML 里搜「字段别名表」 |

## 🛠 开发者说明

仓库里的 `中南大学生工作台.html` 是**单文件原型**——没有构建步骤、没有框架，
整个产品逻辑都在这一份文件里。桌面版不改它一行，而是由
`.build/build-desktop.js` 同步成 `app/src/index.html`，并在 `</body>` 前注入一段
**桌面适配层**（只处理网页做不到的三件事：导出落盘、外链用系统浏览器打开、关掉浏览器右键菜单）。
适配层只在能拿到 `window.__TAURI__` 时才生效。

```bash
# 1) 生成桌面版入口（仓库不含构建产物，必须先跑）
node .build/build-desktop.js

# 2) 出包
cd app && npm install && npx tauri build

# 3) 按命名规则放进「发布」目录 + 同步文档里的文件名
python .build/pack-release.py
```

**发布命名规则**（长期遵守，别再换写法）：

```
中南大学生工作台-v<版本>-<用途>.<扩展名>        # 绿色版 / 安装程序 / 单位部署
ZUEL-StudentWorkstation-v<版本>-Portable.exe    # GitHub 附件用英文名（中文名会被清成 -.exe）
```

版本号以 `app/src-tauri/tauri.conf.json` 的 `version` 为唯一来源，脚本自动读取，不手写。

**目录**

| 路径 | 说明 |
| --- | --- |
| `中南大学生工作台.html` | 产品本体（单文件原型） |
| `中南大学生工作台_方案说明.md` | 需求确认与实现方案（含数据字典、导入合并策略） |
| `中南大学生工作台-用户使用手册.docx` | 给辅导员看的使用手册 |
| `app/` | Tauri 2 桌面工程（Rust 壳 + 打包配置） |
| `.build/` | 构建、回归测试、出包命名脚本 |
| `发布/` | 安装说明（exe/msi 本体已 gitignore） |
