# ZUEL 辅导员工作台

面向高校辅导员的**本机**学生工作台。
把教务 / 学工系统导出的表放进来，自动拼出学生画像、成绩、宿舍与学业预警；
另有一套能真正干活的**奖学金评选**流程。

**数据只存本机，全程不联网、不上传服务器。**

第一次用？去读 [QUICKSTART.md](QUICKSTART.md) —— 3 分钟走完一遍。
想把它改成你们学校的版本？去读 [DEVELOPING.md](DEVELOPING.md)。

**运行环境**：Windows 10 / 11（64 位）；macOS 用 .dmg。程序自带界面运行环境，无需另外安装。

> **Mac 第一次打开**：被系统拦时用「右键 → 打开」放行一次即可（临时签名，只需一次）。

换电脑或重装系统前，记得在「⋯ → 导出备份」里导一份数据文件。

## ✨ 现在能做什么

### 学生管理
- **全部学生**：按学号对齐的名册，支持任意列的显示/隐藏与排序；班级、专业、标签、备注都能筛
- **学生画像**：把教务成绩 + 学工信息 + 宿舍 + 班委任职合成一张完整档案
- **学业预警**：按规则自动挑出需重点关注的学生（有不及格、绩点偏低、关键学期异常等）
- **宿舍看板**：按楼栋 / 寝室聚合，查寝打分表可导出直接打印

### 奖学金评选
一套完整的评选流程，**与学生名册彻底隔离**（评选数据不污染档案）：
- **批量拟定**：筛到某奖 → 勾选多人 → 一次「拟定「国家奖学金」」
- **自动移出**：定完一个人，自动从其他不兼得奖项的名单里移出（单项奖可兼得，仍保留）
- **按专业细分名额**：可按年级内专业人数比例细分，也可平均分或手填
- **细分与表格关联**：表格按专业分组，组头显示「分配 N 名 · 已定 N 名 · 状态」，
  逐专业打勾核对；超额、该专业没分到名额等问题当场提醒
- **导出**：含姓名 / 学号 / 专业 / **推荐奖学金名称** / 全部成绩 / 志愿

### 日常
- **导入指引**：不知道从哪导？软件内点「导入指引」，按系统一步步走
- **多种导入口**：拖文件进来、粘贴 Excel、直接选文件
- **周次校准**：点顶栏周次，告诉它「今天应该是第几周」，之后自动接着往后数
- **锁屏**：顶栏一把小锁，点一下挡住整个屏幕（防旁人看到学生数据），可设密码
- **备份与恢复**：一键导出 / 恢复数据文件
- **批次管理**：每学期一批，互不干扰，可随时切换

## 🏗 仓库结构

```
中南大学生工作台.html        ← 产品本体（单文件，改这个；界面显示为「ZUEL 辅导员工作台」）
app/                         ← 桌面版（Tauri 套壳）
  src/index.html               自动生成，不要手改
  src-tauri/tauri.conf.json    产品名、identifier、图标、打包配置
docs/design/                 ← 视觉设计规范
.build/                      ← 构建与测试脚本（[目录说明](.build/README.md)）
发布/                         ← 打好包的安装程序
CHANGELOG.md                 ← 更新日志
QUICKSTART.md                ← 第一次用？3 分钟走完
DEVELOPING.md                ← 想改成你们学校的版本？看这里
```

**技术上的一句话**：单文件 HTML + 原生 JS，数据存本地，
桌面版用 Tauri 套壳并注入一层适配（导出落盘、外链走系统浏览器、关右键菜单）——
所以同一个产品在浏览器和桌面都能跑，数据格式完全一致。
