## ① 右移：用 transform 做布局，撞上「用 transform 做禁令」

`[class]:hover{transform:none;text-shadow:none;filter:none}` 是第 06 章「禁止一切 hover 位移」的
兜底规则（`中南大学生工作台.html:1869`）。它的特异性是 `[class]` + `:hover` = **(0,2,0)**，
和 `.undo-bar.show` 的 (0,2,0) 打平；打平就比先后，而它在文件里更靠后 → **hover 时 `transform` 变 `none`**。

撤销条靠 `left:50%` + `translateX(-50%)` 居中。`transform` 一没，位移没了，元素左边缘就停在
视口 50% 处 —— 于是整条右移自身宽度的一半（1440px 视口下实测 **+190px**）。

empirical 复刻（`.verify/hover-check.mjs` 的 `[rootcause]` 段，把旧写法按同样的特异性、
同样的先后位置注入当前页面后 hover）：

```
[rootcause] INFO 旧写法 hover 前 x=599.67 → hover 后 x=720（位移 120.33px，transform=none，hovered=true）
```

探针条宽 240.66px，位移正好是一半；`x` 落在 720 = 1440 的 50%，与「居中位移被抹掉」完全吻合。

### 怎么改的：把居中从 transform 里挪出去

最外层新增 `.toast-stack`（`中南大学生工作台.html:947`）：

```css
.toast-stack{position:fixed;bottom:26px;left:0;right:0;width:fit-content;margin:0 auto;
  display:flex;flex-direction:column;align-items:center;gap:8px;z-index:510;pointer-events:none}
```

- **不用 `transform` 居中**：`left:0;right:0;width:fit-content;margin:0 auto` 是纯布局居中，
  那条 hover 规则再怎么改都抹不掉它。
- `.undo-bar` / `.toast` 去掉 `position/left/bottom/z-index`，只保留 `transform:translateY(12px) → 0`
  的纵向淡入。hover 时被改成 `none` 与 `translateY(0)` **视觉等价**，不跳。

> 为什么不「加更高的特异性把 `[class]:hover` 压回去」：那只是让两套意图继续在同一属性上打架，
> 下一个写浮层的人还会再踩一次。把居中从 `transform` 里挪走，冲突在结构上就消失了。

## ② 双提示：不是叠在一起的问题，是「同一件事说了两遍」

原来 toast 与撤销条各自 `position:fixed; bottom:26px; left:50%`，`z-index` 510 / 500。
四条删除路径都是「先 `snapshotForUndo()`（弹撤销条），再 `toast()`（弹提示条）」，
两条完全重合 2.2 秒，长的那条从短的那条两侧露出来 —— 看起来像「两个提示互相遮挡」。

改法分两层：

**结构层（兜底）**：两者进同一个 `.toast-stack`，`flex-direction:column; gap:8px`。
真需要同时出现时（例如撤销条还挂着 30 秒，用户又触发了别的 toast）自动上下排开，
高度随文案换行自适应，不靠 `z-index` 硬压。

**策略层（去重）**：四条路径去掉重复的 `toast()`，撤销条成为这类操作的唯一确认面：

| 位置 | 删掉的 toast | 说明 |
|---|---|---|
| `中南大学生工作台.html:3683` | `已删除 ${nm}` | 撤销条已写「已删除学生：X · 30 秒内可撤销」 |
| `3720` | `已删除 ${arr.length} 名学生` | 同上，换成人次 |
| `7001` | `批次已删除` | 撤销条已写「已删除批次「X」」 |
| `11303` | `已清理评选数据，学生名册与成绩未动` | 「名册与成绩未动」并进撤销条文案：`snapshotForUndo('已清理评选数据（学生名册与成绩未动）')`（`:11299`） |

`undoRestore()` 里那条 `toast('已撤销，数据恢复到删除前')` **保留** —— 点撤销时撤销条正在隐藏，
toast 是唯一反馈。
