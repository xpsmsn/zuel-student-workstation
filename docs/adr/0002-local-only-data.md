# 数据只存本机：不联网、不注册、无后端

所有学生数据保存在使用者的本机——桌面版存在 `%LOCALAPPDATA%\cn.edu.zuel.studentworkstation` 下的 Local Storage，并镜像一份到 `%APPDATA%\cn.edu.zuel.studentworkstation\workstation-data.json`。软件不含任何服务端、账号体系或网络请求。

理由是学生信息属敏感数据：不联网就不必解释数据去了哪，学校也不必为部署与合规做任何事，绿色版拷到任意文件夹即可运行。代价是换机只能靠手动导出 / 导入备份，且同一份数据无法在多台机器之间同步。

## Consequences

- 软件内**不含 AI 调用**：界面上「AI 助理」页只是三张企业微信二维码（学工工作助理 / 鹿晓南 / 综合评定答疑），点开走用户自己的企业微信，不在软件里发起请求。
- 用浏览器直接打开原型、与用桌面版打开，**是两份互不相通的数据**：Local Storage 按来源隔离，桌面外壳是另一个来源。
- 备份与还原必须由软件自己提供（「系统设置 → 数据管理 → 导出完整备份」），没有云端兜底。
- 名册落盘的**加密仍是待办**：v1.0 照旧用 WebView 的 Local Storage，未换 SQLite、未接加密存储（见方案说明 §8.6 / 附录 B4）。
