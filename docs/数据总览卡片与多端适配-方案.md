## 2. 两条根因（都可验证）

### 2.1 环形图是**固定 172×172**，不随卡片放大 → 放进整行必然"左小右空"

- 条形图：`<svg viewBox="0 0 ${W} ${H}">`（`:5720`），`W` 来自 `chartWidth(span)`（`:5726`）→ **宽度自适应**
- 环形图：`<svg viewBox="0 0 ${size} ${size}">`（`:5762`），**没有宽度参数**；CSS
  `.donut-svg{width:172px;height:172px;flex-shrink:0}`（`:658`），图例 `.donut-legend{flex:1}`（`:664`）
- 所以同一个 `donutChart(...)`：在 span 5 的性别卡里（≈450px）比例正常；
  在 span 12 的政治面貌卡里（≈1100px）就是**172px 的环 + 被拉得极宽的图例 + 大片空白**

### 2.2 **空转卡片仍按原 span 占位**

`dashCard()`（`:5800`）只把内容替换成一句提示（`empty ? dash-empty : body`），**span 由调用方写死**。
于是"成绩表没导入"时，4 张成绩相关卡照样按 7/5/12/7 占版面 —— 而它们的提示文字只有一行。

## 3. 目标规则（建议）

| # | 规则 | 落点 |
|---|---|---|
| **R1** | **尺寸跟内容走**：把 span 从"写死"改成"按内容量算" —— 抽象成纯函数 `spanFor(kind, n)`，可直接写断言 | `dashCard` 调用处 |
| **R2** | **空转不占版面**：同一"缺少数据源"的卡**合并成一条**紧凑提示（带「去导入成绩」入口），而不是各占 7/5/12；指标卡里 3 张成绩项同理收成 1 张 | `renderDashBody()` / `renderDashMetrics()` |
| **R3** | **环形图只用在半行卡里**：span ≤7 才用 `donutChart`；整行位置改成横向条形（或让 `.donut-svg` 可放大，见待拍板 2） | 卡片选型 |
| **R4** | **断点映射**：`≤1180px` 由"每卡整行"改为**两列**（现在 `:594` 把所有 span 都映射成整行）；改时**必须同步** `chartWidth()` 里"≤1180 按整行算"的口径（`:5732`），否则图表宽度与卡片实际宽度会不一致 | CSS + `chartWidth()` |

**R1 的具体建议值**（都可写断言）：

| 卡片类型 | 规则 |
|---|---|
| 环形（性别/政治面貌…） | 类别 ≤3 → 5；4–6 → 5；>6 → 7（超过 6 类环形已不可读，考虑改横条） |
| 横向条形（专业/民族/生源地） | 条数 ≤5 → 5；6–10 → 7；>10 → 12 |
| 纵向条形（班级人数） | 类别 ≤6 → 5；7–12 → 7；>12 → 12 |
| 名单类（学业预警/关注提醒/学籍异常…） | 固定 5 |
| 比例条（数据完整度） | 固定 7 |
| 单图整行（班级平均成绩） | 仅当类别 >12 才用 12，否则 7 |
