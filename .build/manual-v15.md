## 版本更新说明（v1.5）

### ① 顶栏日期与周次 + 系统设置

- 顶栏「中南大学生工作台」右侧新增**日期周次徽章**：如「9月22日 周二｜2026-2027 学年第一学期 · 第 4 周」，跨天/跨周自动刷新。
- 侧栏新增「系统 → **系统设置**」：可维护**学期名称、第 1 周开始日期（周一）、总周数**，保存后顶栏立即更新；开学前显示「未开学」，超出周数显示「假期中」。
- 原侧栏「其他」重新梳理为两组：**数据管理**（取数指引 / 导入学生数据 / 导入成绩 / 导入历史 / 备份与恢复）与**系统**（系统设置 / 个人中心），两组都可折叠。

### ② 我的班级：拖拽排序

- 侧栏「我的班级」列表现在可以**按住拖动排序**：拖起半透明浮起、目标位置显示品牌色插入线、松手后轻弹落位。
- 排序结果会被记住；新出现的班级自动排在最后。

### ③ 宿舍看板：跨宿舍拖拽调宿

- 宿舍看板里，**有人的床位可以直接拖到另一个宿舍**：目标房间虚线高亮，松手确认后自动更新该学生的宿舍信息（兼容「宿舍楼 + 房间号」三列和「宿舍」单列两种表结构）。
- 需要撤销时，把 TA 再拖回去即可。

### ④ AI 辅导员与校历：排版升级

- AI 辅导员页改为**左右双卡**：左边扫码卡（左图右文），右边「什么问题适合问鹿晓南」说明卡。
- 校历作息页改为**两张图并排**：左校历、右课堂时间表，一屏同览；窄窗口自动落成上下排布。点击图片仍可全屏放大。

### ⑤ 导入历史与一键复原 + 数据本地固化

每次导入学生数据或成绩，都会自动留档一条记录（时间 / 类型 / 文件名 / 批次 / 新增 / 更新 / 异常），侧栏「数据管理 → 导入历史」可查看：

- **一键复原**：把对应批次的数据回退到该次导入之前；复原前会自动把当前数据备份成 CSV，绝不越复原越丢。
- **数据本地固化（桌面版）**：所有数据每次保存时自动镜像写入应用数据目录（磁盘文件），**清理浏览器缓存 / 重置 WebView 后，下次打开自动恢复**，不再受浏览器缓存影响。「系统设置」页可查看固化状态、「导入历史」页顶部也有标识。
- 浏览器版（直接双击 HTML 打开）无磁盘写入能力，快照暂存浏览器本地存储，页面会明确提示；建议使用桌面版获得完整固化能力。
