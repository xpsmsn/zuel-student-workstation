# 版本更新说明（v1.9）

> 本版关键词：**新手引导跟着做一遍就能完成取数与导入**、**宿舍查寝卫生打分表（A4 横向可打印）**。

## 一、新手引导重做：跟着点一遍，两份文件就到手

打开工作台后会自动弹出引导（也可以在左侧点「取数 · 导入指引」随时重看）。这一版把引导改成了**分步实操向导**，一共 6 步，每一步都给一个可以点的按钮：

- **开始之前**：说清这一趟只做两件事（导学生信息、导成绩单），大约 5 分钟，需要统一身份认证账号。
- **① 取学生信息**：点「打开「智慧学工」→」直接跳登录页；下面列出「学生数据 → 学生基本信息 → 导出 → 自定义导出 → 字段全选 → 保存 .xlsx」的完整路径。做完点「✅ 学生表已经存好了」。
- **② 取成绩单**：点「打开「综合教务系统」→」，同样给出「成绩管理 → 查询分析统计 → 专业成绩单」的路径。上课专业可多选，一份成绩单能装下你带的全部专业。
- **③ 导入学生表**：点「现在导入学生表 →」直接打开导入框，不用自己去右上角找按钮。导入方式（新增 / 覆盖当前批次 / 新建批次）也在这里解释清楚。
- **④ 导入成绩单**：点「现在导入成绩单 →」。成绩按学号自动挂到人身上，学生表里有、成绩单里没有的显示「暂无成绩」。
- **好了**：告诉你左侧能按班级 / 关注点筛人，「列设置」「字段设置」决定看哪些列和字段。

向导上方有一条**进度清单**：「学生基本信息表（智慧学工）」「专业成绩单（综合教务）」，存好哪份就勾哪份，随时知道还差什么。

**找不到引导了怎么办？** 三条路都能进：

1. 左侧栏「取数 · 导入指引」（带 NEW 小标）；
2. 该页面右上角「🎬 从头看一遍新手引导」；
3. 「个人中心」里也有「从头看一遍新手引导」。

在「取数 · 导入指引」页，如果学生表已经导进来了，右上角会出现「继续第 ④ 步 · 导入成绩」——导完学生表可以直接接着走，不用从头再翻一遍。

> 说明：引导只在第一次进入时自动弹一次；点过「跳过，直接开始」也算看过，之后就靠上面的三个入口手动打开，不再打扰你。老版本升级上来的用户不会被引导拦一道。

## 二、宿舍看板：导出「宿舍查寝卫生打分表」（A4 横向打印）

进门在左侧「宿舍看板」，卡片右上角多了一个「🖨 查寝打分表」按钮。点开是一个设置弹窗：

| 项目 | 说明 |
| --- | --- |
| 表格标题 | 默认「宿舍卫生查寝打分表」，可改成「XX学院 X 月查寝打分表」这类 |
| 检查日期 | 默认今天 |
| 检查人 | 默认取「个人中心」里填的姓名 |
| 学院 / 单位 | 选填，留空则表头不显示这一项 |
| 每项满分 | 默认 10 分，1~100 可调 |
| 打分项 | 默认 8 项：地面、门窗、床铺、桌面、物品摆放、卫生间、阳台、安全用电。**用逗号分隔可自由增删改** |
| 导出范围 | 「当前筛选」（就是你上面选好性别 / 楼栋 / 排序的结果）或「本批全部」 |
| 打印住宿人员名单 | 勾上则每间房打印住宿人姓名 + 床位号，方便点名、找人 |

**为什么是 A4 横向？** 这张表至少要放下「序号 / 宿舍楼 / 房间 / 住宿人员 / 人数 / 8 个打分项 / 总分 / 备注」共 15 列，竖版会被压成一列一列很窄、写不下分。所以固定按 **A4 横向**排版，表头在每一页自动重复，表格按**楼栋 + 房号自然序**排列（101 → 102 → …），检查组拿着不会漏查。

**怎么生成与打印？**

- 桌面版：点「生成打分表」后，文件存到 Windows「下载」文件夹，并**自动用默认浏览器打开**。在打开的页面里按 **Ctrl + P**，打印机设置里确认选的是**横向**，直接打印或另存为 PDF。
- 浏览器版：直接在新标签页打开同一个页面，同样按 Ctrl + P 打印（手机上请先把文件传到电脑）。

表尾留有「检查人签字 ____ 日期 ____」和「每项 X 分 / 共 N 项 / 满分 XX 分」的说明，打印出来即可直接用。

> 打印出来的分数栏是**空表**（供现场手写）；它的用途是「一张纸带一支笔去查寝」。如果想在电脑里记录打分，可在表格导出后自行录入。

## 三、演示数据的宿舍更贴近真实

内置演示数据这一版重新编了床位：80 名学生按性别编成 **25 间房、每间 2~4 人**、床位从 01 床连续编号，男女不混寝。以前演示数据里每人各占一间房（80 间、每间 1 人），宿舍看板和查寝打分表看上去都很假，现在首次打开就能看到接近真实的房间列表，学生详情页的「室友」列也不再是空的。

> 只影响内置的「演示数据」批次，你导入的真实数据不受任何影响。想清掉演示批次，在「数据总览 → 批次管理」里删除即可。

## 四、修复

- 修好了「新用户 / 老用户都找不到新手引导」：引导页的侧栏入口在早前一次界面调整中连同分组一起被误删，只剩「首次进入自动弹一次」，一旦点过或点过「跳过」就再也进不去。现在侧栏常驻入口（带 NEW 小标）、指引页右上角、个人中心三处都能重看。
