# 版本更新说明（v1.9.3）

> 本版关键词：**界面顺眼了**、**两张二维码长一个样了**、**筛选能一次勾好几个了**。
> 本版**只调界面和操作手感，没有改数据格式** —— 直接升级，你已有的数据一动都不动。

## 一、AI 辅导员页重新排版

以前这一页三块东西挤在一起：左边一张带图的卡、右下角一张横跨两列的卡，旁边还挂着
一张「什么问题适合问鹿晓南」的说明卡，看着有点乱。现在改成**两个人各占一张卡，左右并排、一样宽、一样高**：

- **那张「什么问题适合问鹿晓南」的说明卡删掉了** —— 它讲的内容（请假销假、奖助学金、缓考学籍）
  本来就是左边那张卡该说的话，直接并进了它的三条要点，不再单占一块地方。
- 两张卡从上到下的次序完全一样：**标题 → 一句话分工 → 二维码 → 能问什么 → 按钮**，
  眼睛不用在两个版式之间来回切换。
- 窗口拉窄的时候（小于 980 像素）会自动变成上下两栏，不会挤成一条。

## 二、两张二维码统一了格式

以前两张码的图片大小、留白、底色都不一样（一张带着深色底板和标题字，一张是干净的小码），
并排放着明显不齐。现在：

- **去掉背景，只留二维码本身。**
- 两张都用**同一个 200×200 的白底圆角外框**，二维码按比例居中填满，**外框大小完全一致**。
- 白底是**固定在框上的，不跟着主题变**：切到深色主题时二维码依然是白底黑码
  （不然"黑底上的黑码"根本扫不出来）。

## 三、「关于」里的二维码删了，换成更好用的「复制链接」

「系统设置 → 关于」是看版本号和作者的地方，塞二维码意义不大，**已删掉**（软件 / 存储 / 作者 / 版本号都还在）。

二维码留在「AI 辅导员」页就够了，并且**两张码下面各加了一个「复制链接」按钮**：

- 按一下，就把这个机器人的**企业微信链接**复制到剪贴板，**可以直接粘进企业微信群 / 班级群** ——
  学生点开就能用，不用要求每个人都去扫二维码。
- 旁边保留「在浏览器打开」，方便你自己先看一眼点开是什么样子。

> 小提示：两个按钮复制的是不同的链接，别粘混了 —— 左边是鹿晓南（制度流程），右边是综合评定答疑机器人。

## 四、筛选从"点一个就收起"改成复选框

以前筛选是系统自带的下拉框，**勾一个值它就自动收起来**。想按"男 + 女"或者
"党员 + 积极分子 + 团员"这种多个值一起筛，只能反复点开、反复找，很费劲。现在换成复选框面板：

- **点一下展开**，里面每个取值一个复选框，**勾选立刻生效、面板不关**，
  一次就能把几个值都勾上，勾完点「完成」或者点面板外面就收起。
- **按钮上直接显示你选了什么**（比如显示"男、女"）；勾得多了就显示一个数字角标，
  不用点开也知道现在筛的是什么。
- 面板里有「**清除本组**」，只清这一个字段，不会动你设的其它条件。
- **筛选规则没变**：同一组里选多个值是"**或**"的关系，不同组之间是"**且**"的关系
  （和以前完全一致，只是操作方式变顺手了）。
- 「总览」页的筛选条也一起换了。
- 注意「**预设视图**」那一个**仍然是单选** —— 它本来就是"一整套视图"，不是可以多选的筛选项。

## 五、升级注意

- 直接覆盖安装，或换用新版绿色版即可，**升级不会丢数据**（数据存在本机的应用数据目录里）。
- 想确认数据固化正常：**系统设置 → 数据固化** 应显示「已开启」；想手动再存一份，点
  「立即固化一份到磁盘」。
- 本版不涉及导入规则与字段识别，上一版修复的 `.xls` 名册导入、表头自动定位、名册自动同步政治面貌
  **全部照旧可用**。
