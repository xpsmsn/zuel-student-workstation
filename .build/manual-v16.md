## 版本更新说明（v1.6）

### ① 窄窗口顶栏自适应

以前把窗口拖窄会出现顶栏文字竖排、按钮被压变形的情况，现在按窗口宽度**逐级收敛**，永远保持一行、横排整齐：

- 宽度不足时，依次自动收起「导出当前结果」、名言栏、「导入数据」文字。
- 「显示模式」从三个小按钮（☀ / ☾ / ◑）**收成 1 个按钮**，点一下循环切换明亮 → 暗黑 → 护眼。
- 「导入数据」收成圆形 **+** 按钮，鼠标悬停有提示，功能不变。
- 校徽旁的「中南大学生工作台」文字、头像旁的姓名会随宽度收起，只留图标，不再挤压换行。

### ② 数据管理全部收进「系统设置」

- 侧栏不再单独占一组「数据管理」。**取数指引 / 导入学生数据 / 导入成绩 / 导入历史 / 备份与恢复 / 打开备份文件夹** 六项，全部集中到 **系统设置 → 📦 数据管理**，做成一排卡片，一眼看全。
- 侧栏因此精简为**两组**：「常用工具 / 我的班级 / 关注视图」等内容组，加一个「系统」组（系统设置、个人中心）。

### ③ 备份与恢复：看得见的上次备份时间

- 「数据管理」区底部常显一行备份状态，例如「**上次备份：2026/09/20 21:40 · 已 1 天未备份**」；从没备份过会以醒目颜色提示「还没有导出过备份 · 建议现在就导出一份」。
- 新增「**📂 打开备份文件夹**」按钮：桌面版一键打开系统「下载」目录，导出与备份文件都在里面；浏览器版会提示改用桌面版。
- 备份行为写入应用数据，换台电脑打开也知道自己上次备份的时间。

### ④ 系统设置与个人中心：各管一摊

两边职责彻底分开，不再重复：

| 页面 | 管什么 |
| --- | --- |
| **系统设置** | 🎨 外观与主题（三张卡片：明亮 / 暗黑 / 护眼，带适用场景说明）· 📅 学期与周次 · 📦 数据管理 · 🔒 数据固化（防清缓存丢失）· ℹ️ 关于 |
| **个人中心** | 👤 个人资料（姓名 / 学院 / 电话 / 负责班级 / 头像）· 🔐 安全（修改密码）；页面底部一行跳转提示「找其他设置？→ 系统设置」|

- 「外观与主题」从顶栏小按钮升级成**可视化卡片**：每张卡片标注什么场景用哪种模式（白天办公 / 夜间值班 / 长时间护眼），点一下就换。
- 「保存学期信息」按钮改为常规宽度，不再横贯整张卡片。
