## v1.9.2 —— 修「二次导入一个人都进不来」+ 名册自动同步

面向高校辅导员的**本机学生工作台**：把系统里导出的学生信息表 + 成绩单放进来，自动拼出每个人的画像、成绩、宿舍与预警。**数据只存本机，全程不联网、不上传服务器。**

### 🐞 这个版本修了什么

拿「入党积极分子名册」去更新学生政治面貌时，会出现两种都很难受的结果：

- 学校发的名册是 **`.xls`（Excel 97-2003 旧格式）** 时，导进来的是 **一堆"软件模板里的人"**；
- 换成 `.xlsx` 之后，又变成 **导入 0 人**。

**两个根因，这次一并修掉：**

| 根因 | 为什么会出现上面那种结果 | 现在怎么做 |
|---|---|---|
| 内置的表格解析库是 SheetJS 的**精简版**，**根本不支持 `.xls` 旧格式** | `.xls` 必然解析失败，而失败后代码会**静默换成内置演示数据导入** —— 于是库里凭空多出几十个"软件模板里的人"，还以为是自己导错了 | 换成**完整版**（支持 `.xls` / Excel 97-2003 / CFB）；并且**解析失败不再顶替**，改为明说"这个文件打不开"并给出常见原因与下一步，**一个字都不入库** |
| 程序写死了「**Excel 第 1 行就是表头**」 | 这类表格的第 1~3 行是「附件6：」标题、盖章栏、填报日期，**真正的表头在第 4 行**。整表错位后列名被认成「附件6：」，学号列识别不出来，每一行都因"学号为空"被跳过 → **导入 0 人** | **表头自动定位**（优先找"同时含学号与姓名"的那一行），顺带把表头正下方的「培养联系人 1\|2」子表头、表尾的签名与说明行剔除；老样式的表完全不受影响 |

### ✨ 这个版本新增了什么

**1. 积极分子名册 → 政治面貌自动同步**
既是名册，那"把这些人改成入党积极分子"本来就是你该做的事，让程序顺手做掉：
匹配到学号的自动同步为「入党积极分子」，名册里的党支部、递交申请书时间、确定为积极分子时间也一并写入档案。
两道闸门保安全：**已是党员 / 预备党员 / 发展对象的一律不降级**；名册自带政治面貌列则以名册为准。

**2. 班委词条范围扩大**
「班干部」「班级委员」「班级职务」「职务」「担任职务」都归一到「班委」，班委成员视图直接能用。

**3. 综合评定答疑机器人二维码**
「AI 辅导员」页新增一张卡片（内联二维码，离线可显示），带「复制链接（发群公告用）」按钮；
「系统设置 · 关于」里也放了一份。分工：**制度流程问鹿晓南，综合评定口径问它。**

**4. 首次引导之后的「页面浮窗批注」导览**
走完新手引导后自动浮出一圈批注，7 步逐块点出批次条、导入按钮、侧栏、取数指引、
筛选与列设置、关注视图、个人中心。挖洞式高亮，目标元素照样看得清；随时可跳过。
**老用户升级不会被打扰**（老数据一律视为"看过"），想重看去：个人中心 →「重看页面导览」。

### ⬆️ 从旧版升级

直接覆盖安装、或换用新版绿色版即可 —— 数据存在本机应用数据目录里（桌面版每次保存都会自动
镜像一份 `workstation-data.json`），**升级不会丢数据**。
在「系统设置 → 数据固化」能看到当前状态（桌面版应显示**已开启**）；想手动再固化一份，点
「立即固化一份到磁盘」。

### 🔧 开发者说明

- 表头定位在 `locateHeaderRow()` / `buildRawRows()`；名册识别在 `detectSheetKind()`，
  同步规则在 `applyRosterRule()`（`ROSTER_PROTECT` 正则挡降级）；解析失败提示在 `openFileError()`。
- **别再把 SheetJS 换回 mini 精简版**：精简版没有 `parse_xlscfb` / `CFB`，`.xls` 会直接读不了。
  当前内联的是完整版（`xlsx.full.min.js`，639,124 字符）。
- 「页面浮窗批注」导览的锚点全用 `data-tour` 属性；新增步骤只需往 `TOUR_STEPS` 里加一条。
- 机器人二维码内联为 `QR_ROBOT` 常量（284×284、16 色、5.3KB）。**改图后必须用
  `node .build/qr-check.js <png>` 验一遍"扫得出来"** —— 二维码压缩过头会失效。
- 回归测试：`node .build/test-import.js 中南大学生工作台.html`（**38 条**断言：表头定位 /
  非人员行过滤 / Excel 真实行号 / 名册同步与不降级 / 班委与学号同义词 / 老表不受影响）；
  真实文件端到端 `node .build/real-roster-check.js <页面URL> <真实.xls>`（**9 条**）；
  真机导览 `node .build/shot-v192.js <页面URL> .build`（7 步浮窗批注定位 + 两个二维码解码）。
- 出包后跑 `python .build/pack-release.py`：按 `中南大学生工作台-v<版本>-<用途>.<扩展名>`
  的统一规则把三个产物放进「发布」目录，并同步安装说明 / README 里的文件名。
