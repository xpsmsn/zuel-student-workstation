## v2.3.0

面向高校辅导员的**本机**学生工作台。把教务 / 学工系统导出的表放进来，自动拼出学生画像、
成绩、宿舍与学业预警，并有一套能真正干活的**奖学金评选**流程。

**数据只存本机，全程不联网、不上传服务器。**

### 这一版修好了什么

**「导出 → 在 Excel 里改 → 导回来」终于闭环了**

之前成绩导不回来，原因是三个问题叠在一起：
1. 导入只读**第 1 张工作表**，而成绩写在第 2 张 → 改为遍历所有工作表按列分流
2. CSV 导出的成绩列带 `成绩·` 前缀（防与档案列重名），导入侧不认识 → 改为自动剥掉前缀
3. 建新批次时忘了把成绩挂上去 → 新批次把刚导入的成绩清空

现在 **xlsx 与 csv 两种格式**都能完整往返：4 份真实系统导出表走一遍，
档案 37 列一列不丢、加权平均成绩 162 人、评选 132 条。

**交互不再乱跳**

- 筛选 / 排序 / 切预设后，页面不再跳回顶部，停留位置保持不变
- 筛选下拉面板内部滚动也不再归零 —— 勾了靠后的选项能看见自己勾了什么
- 列设置里每勾一列都跳回第一行 → 改为只切换该行高亮

**宿舍看的是房间，不是某个人**

- 筛选选项从「滨湖1栋629-01」变成「滨湖1栋110」（按房间，不再按床位）
- 宿舍填「-」的学生**归入「未分配宿舍」单独警示**，不再被当成一个房间而误报「男女混住」

**奖学金评选与主数据彻底隔离**

- 评选区不再存姓名 / 专业（身份列一律从名册取，避免两份数据打架）
- 主数据里的评选列不默认勾选（数据仍保留，想看时可勾）
- **新增「清理评选数据」按钮**：只清评选区，名册与成绩一律不动，30 秒内可撤销

**其他**

- 周次按**每周第一天**计算（默认星期日，周日属新一周）：设置页里一个日期框即可，
  选 9/9(周三) 会自动对齐到那一周的周日 9/6
- 系统设置与个人中心按统一设计规范重排（字号四档、8px 栅格、圆角归位、去掉多余图标）
