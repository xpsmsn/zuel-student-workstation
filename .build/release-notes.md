## v2.7.0

面向高校辅导员的**本机**学生工作台。把教务 / 学工系统导出的表放进来，自动拼出学生画像、
成绩、宿舍与学业预警，并有一套能真正干活的**奖学金评选**流程。

**数据只存本机，全程不联网、不上传服务器。**

### 这一版改了什么

**主线是「日程规划」页推倒重做**（v2.6 系列 12 个小版本积累），外加常用筛选管理、
引导 / 导览对齐最新界面与一批显示 / 交互 / 数据细节修复。

**1. 日程规划：从月历翻页改成「双周日历看板」**

- 14 天两行、每周一行（周次徽章 + 7 天），**课表 / 待办 / 紧急事项直接落在日期格子里**
  （最多 3 条 + 「还有 N 项」折叠），一眼看出哪天最挤
- 点开某一天，右侧**按时段排序列出当天安排**；添加待办带起止时间与优先级
- 录课表时大节下拉自动带出上课时间
- **时长自动计算**：选 30–180 分钟自动回填结束时间，反向亦然；跨午夜截断到 23:59
- 周次徽章跟学期设置实时对齐（顶栏校准后日历同步刷新）

**2. 课表交互修复：单击不再「点一下就没了」**

原先点条目 = 直接删除。现在**单击 = 选中展开详情**（周几 · 大节 · 时间 · 周次），
删除走显式按钮 + toast，连点同条目不抖动，双击空白格有防重开守卫，条目支持 Enter 键盘操作。

**3. 常用筛选：补齐管理能力**

筛选条上的小标签补上「✎ 改名」「× 删除」行内操作；同名保存改为覆盖确认；应用筛选带 toast 反馈。

**4. 新手引导与页面导览：对齐最新界面 + 支持键盘**

- 导览从 11 步扩到 **12 步**：新增「日程规划」专步，侧栏总览补齐日程规划与奖学金评选，
  筛选步补常用筛选说明
- **键盘操作**（现场演示不用碰鼠标）：回车 / → 前进、← 后退、Esc 跳过；引导末步回车 = 开始使用
- 引导初始焦点改落在「下一步」主按钮（原先落在「跳过」上，回车会误触跳过）

**5. 显示与数据细节**

- 关于区新增**应用二维码**（Web 版分享链接，手机扫码直达）
- 查寝评分表 10 → 11 列；课表导入同步日历带大节时间；预置关注标签 15 个
- 手机端输入不再被软键盘弹出的 resize 重绘清空（断点跨越才重绘）
- 触屏复选框放大到 22px，与文字对齐顶差 ≤ 4px
- 版本号显示修正（此前长期停留在 v2.5.0）

### 旧版本升级

从 v2.3.x / v2.4.x / v2.5.x / v2.6.x 升级：覆盖安装即可，本机数据不丢。
`cn.edu.zuel.studentworkstation` 这个标识符保持不变。

> ⚠️ 升级前请**先从托盘彻底退出正在运行的旧版本**（右键托盘图标 →「退出」，不是关窗口）。
> 程序是单实例的：旧版还在跑时双击新版，只会把旧窗口拉到前面，不会启动新版。
