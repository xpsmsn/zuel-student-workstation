## v2.5.0

面向高校辅导员的**本机**学生工作台。把教务 / 学工系统导出的表放进来，自动拼出学生画像、
成绩、宿舍与学业预警，并有一套能真正干活的**奖学金评选**流程。

**数据只存本机，全程不联网、不上传服务器。**

### 这一版改了什么

**这一版没有新增功能页**，而是把每天都要用的界面按无障碍标准与统一设计系统重新校准了一遍。

**1. 文字对比度：三套主题全部达到 WCAG AA**

二级 / 三级文字、警示与成功色、主按钮白字，原先有一半在 4.5:1 以下（三级文字只有 2.73:1）。
现在按各主题的真实底色实算，亮色 / 暗色 / 护眼三套主题**全部达标**——不是拍脑袋调深一档。

暗色的强调色还拆了两个令牌：链接用 `--accent`，实心按钮底用 `--accent-solid`。
同一个深蓝既当链接又当按钮底时，必有一处不达标（之前卡在 3.19:1）。

**2. 键盘能走完整个工作台**

- 每个输入框、按钮、表格行都有**看得见的焦点环**（原来有 18 处把焦点环关掉了）
- 左侧模块、表格行、统计卡这些「整块可点」的区域，**Tab 能到、Enter / 空格能激活**
- 右上角菜单、筛选、批量操作同理；切换模块后焦点自动落回当前模块

**3. 弹窗与提示：屏幕阅读器能听见**

确认框是标准对话框（`alertdialog` + 模态），Tab 在框内环绕、Esc 关闭、关掉后焦点回到原按钮，
初始焦点落在「取消」——以前顺手一回车就把框关了。

**4. 撤销条：不再右移，也不再和提示条互相遮挡**

有老师反馈：「撤销条鼠标移上去会右移，而且好像有两个提示叠在一起」。两个独立的问题都修了：

- **右移**：撤销条靠 `translateX(-50%)` 居中，而全局有一条「禁止 hover 位移」的规则会把它抹掉，
  一 hover 就右移半个条宽。现在改成左右贴边 + `margin:0 auto` 居中，没有位移可抹
- **两条提示**：删除学生 / 批量删除 / 删批次 / 清理评选数据，原先会在弹撤销条的同时再弹一条同义提示。
  现在撤销条是唯一确认面，两条同时出现时也纵向排开、不再压在一起

**5. 字号、字重、圆角收进设计系统**

| 维度 | 改前 | 改后 |
|---|---|---|
| 字号 | 34 个数值档 | 4 档正文（24 / 18 / 15 / 13）+ 图标 32 |
| 字重 | 17 种（含 620 / 660 / 720 这种） | 只有 400 / 600 |
| 圆角 | 26 档 | 0 / 6 / 12 / 50% |
| 字体栈 | 7 种（含永远加载不到的 Inter） | 1 套 |

**6. 排序、窄屏与触控**

- **多级排序可以逐级取消**：`↑班级① ×` `↓成绩② ×`，点哪一级撤哪一级；原来只能一键全清
- **窄屏卡片模式补了工具条**：卡片化后表头被隐藏，全选和排序入口跟着消失——现在在卡片上方
- **横向滚动首列粘住**：勾选框列固定，辅导员备注不再被挤出视口
- **可点击提示不再只能 hover 才出现**（统计卡「查看明细」、告警箭头、备注删除），触屏也发现得了
- **触控命中区补到 44×44**

**7. 顺手修掉两个「看着正常、其实早没生效」的 bug**

- 切筛选后**滚动位置与焦点的记忆从 v2.3.0 起一次都没跑过**（取浏览器内置方法时拿错了原型层，静默退出）。
  滚动"看着没坏"是因为浏览器自己会保持，但**焦点确实会掉回页面顶部**
- 重绘瞬间按下标还原焦点会指偏（新节点还没补上 `tabindex`，数量短暂变少）。现在按 name / placeholder /
  class 优先解析，只有当这些都失效才退回下标

### 旧版本升级

从 v2.3.x / v2.4.x 升级：覆盖安装即可，本机数据不丢。`cn.edu.zuel.studentworkstation` 这个标识符保持不变。

> ⚠️ 升级前请**先从托盘彻底退出正在运行的旧版本**（右键托盘图标 →「退出」，不是关窗口）。
> 程序是单实例的：旧版还在跑时双击新版，只会把旧窗口拉到前面，不会启动新版。
