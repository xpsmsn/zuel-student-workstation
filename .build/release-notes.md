## v2.4.5

面向高校辅导员的**本机**学生工作台。把教务 / 学工系统导出的表放进来，自动拼出学生画像、
成绩、宿舍与学业预警，并有一套能真正干活的**奖学金评选**流程。

**数据只存本机，全程不联网、不上传服务器。**

### 这一版改了什么

**1. 剔除规则精简成一条**

原来给了一堆条件（无总成绩 / 二学位班级 / 第二学位班级 / 手动名单），实际只有一种情况要剔：

- **只剩「总成绩为 0 或为空」**：导出表里这一项缺了、写成 0，或干脆没这一列 —— 没成绩就没法参与排序
- **「二学位 / 第二学位班级」两条已删除**：专业名是身份信息，不该拿来决定一个人能不能参评
- **手动剔除名单保留**（个别情况仍可单独摘出去）
- 顺带修了个隐藏问题：以前「总成绩 0」会被内部当成空串，现在数值 0 如实识别、也如实显示成 `0`

**2. 按专业细分：可以「取消某个专业的分配权」**

细名额的时候，常遇到某些专业不该参与分配。现在每个专业右边有个**「不参与分配」**开关：

- 勾上后该专业**不占名额**——名额**只在剩下的专业之间重新分配**，不是简单给 0

  > 例：国家奖学金 5 个名额，金融学 5 人 / 会计学 3 人 / 经济学 2 人。
  > 都不排除 → 2 / 2 / 1；把「会计学」设为不参与分配 → **金融学 4 / 经济学 1**（5 个名额一个不浪费）。

- 「按比例建议 / 平均分建议」会**跟着开关实时重算**，不用关掉弹窗再打开
- 已排除的专业：行变灰、名字加删除线、名额框禁用
- 保存后记得住；表格的专业分组头里显示**「不参与分配」**，不再误报成「该专业没分到名额」

**3. 细分弹窗排版修正**

上一版加开关后，专业名被输入框和开关挤成了省略号（看不见）。
现在改成**两行式**：专业名独占一行、拿满整行宽度，名额和开关在下一行。再长的专业名也放得下。

> 如果你是从 v2.4.3 或更早升上来的，**v2.4.4** 的批量拟定流程重做也在里面：
> 批量条内嵌「拟定为 [奖项下拉]」，在「全部候选人」也能一步「选人 → 选奖项 → 拟定」；
> 「取消拟定」改成了只在真有拟定时才出现的「清除拟定（N 人）」。
