## v2.4.1

面向高校辅导员的**本机**学生工作台。把教务 / 学工系统导出的表放进来，自动拼出学生画像、
成绩、宿舍与学业预警，并有一套能真正干活的**奖学金评选**流程。

**数据只存本机，全程不联网、不上传服务器。**

---

### 附件怎么选

GitHub 不支持中文文件名，附件用英文名，下载后按下表改名即可。

| 附件（下载得到的名字） | 改名成 | 适合谁 |
|---|---|---|
| `zuel-workstation-v2.4.1-setup.exe` | ZUEL 辅导员工作台-v2.4.1-安装程序.exe | **多数人选这个**：双击按向导装，不需要管理员权限 |
| `zuel-workstation-v2.4.1-portable.exe` | ZUEL 辅导员工作台-v2.4.1-绿色版.exe | 免安装：复制到任意文件夹双击 |
| `zuel-workstation-v2.4.1-x64.msi` | ZUEL 辅导员工作台-v2.4.1-单位部署.msi | 学校信息办统一部署 |
| `zuel-workstation-v2.4.1-macOS-universal.dmg` | ZUEL 辅导员工作台-v2.4.1-macOS.dmg | **Mac**：Intel 与 Apple 芯片通用 |
| `install-notes.txt` | 安装说明.txt | 打印版说明 |

> 运行环境：Windows 10 / 11（64 位）；macOS 用 .dmg。程序自带界面运行环境。
> **Mac 第一次打开**：被系统拦时用「右键 → 打开」放行一次即可（临时签名）。

### 这一版修好了什么

**1. 重写文档：README / 快速上手手册 / 其他院校开发指南**
- README.md 不再鸣谢，只讲这是什么、怎么用
- 新增 `QUICKSTART.md`：3 分钟带新老师走完导入 → 总览 → 评选 → 找数据
- 新增 `DEVELOPING.md`：跨校迁移 5 步走 + AI 工具二次开发指引

**2. 工程化整理**
- `.build/` 28 个脚本按职能归入 4 子目录（sync / pack / test / archive）
- 原型 6 大区注释封皮：方便定位代码段

**3. 演示数据更明显是「演示数据」**
- 内置 71 名「演示学生 01..71」+ 占位身份证/电话/地址
- 上一版的数据是批量虚构的，但因过于拟真可能让看到截图的人产生误解
- v2.4.1 起所有占位字段都明显是占位（`演示学生 01` / `110000YYYYMMDDxxx` / `1380000XXXX` / `XX省XX市演示路`），老师首次打开就能识别是占位

**4. 协议改为 Apache 2.0**
- 见 `LICENSE` 文件
