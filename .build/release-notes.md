## v2.4.3

面向高校辅导员的**本机**学生工作台。把教务 / 学工系统导出的表放进来，自动拼出学生画像、
成绩、宿舍与学业预警，并有一套能真正干活的**奖学金评选**流程。

**数据只存本机，全程不联网、不上传服务器。**

### 这一版修好了什么

**1. 奖学金评选：可配置的剔除规则**
- 新增「剔除规则」设置面板，老师自己决定**什么要剔除、什么要保留**（不再写死）
- 支持：无总成绩 / 二学位班级 / 第二学位班级 / 手动输入学号名单
- 勾上的规则对**所有奖项**生效（剔除的人什么奖都不能参评）

**2. 列设置：单项奖筛选更好用**
- 新增「列设置」面板，可**关闭/打开**任意列（总成绩、智力水平评价、B1~B5…）
- 支持**拖动排序**，把最关心的分数列拖到前面

**3. 评选流程打磨**
- 勾选学生后**立即**出现「拟定」批量操作条（修了勾选后按钮不出现的 bug）
- 勾选 / 全选不再把页面跳回顶部
- 新增「单独清除某个奖项的拟定」：进度卡上点「清除拟定 N」即可，不用清空全部

**4. 奖学金页面整体重设计**
- 工作台式四层结构：页面头 / 视图工具条 / 评选进度 / 候选人表格
- 进度卡改为**横向**布局，奖项名完整显示、不截断
- 评选进度区默认展开，可一键「收起/展开」
- 区头压成单行，让出更多空间给数据
