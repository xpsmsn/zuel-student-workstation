## v2.1.1 —— 两处「该生效却没生效」的修正

面向高校辅导员的**本机学生工作台**：把系统里导出的学生信息表 + 成绩单放进来，自动拼出每个人的画像、成绩、宿舍与预警。**数据只存本机，全程不联网、不上传服务器。**

> 本版**没有数据格式变更**，升级不动你已有的数据。Windows 与 macOS 两个平台都有新包。

### ☑️ 修：取消勾选的字段，在「新建批次」下不生效

导入第二步可以逐列取消勾选（比如不想把「民族」导进来）。原先这个勾选**只在「新增 / 合并」下生效**：
同一个勾选框，选「新增 / 合并」能排除掉，选「**新建批次**」却照样把那一列导进来。

原因是那道过滤只做在了两条导入路径上，第三条漏了。现在三条路径都会遵守你的勾选。

### 🎯 「需重点关注」不再把「军训备注」算进来

原来这个名单认三类信号：成绩表的「不及格门数」、学生表的「挂科情况」、学生表的「军训备注」。
**现在摘掉「军训备注」**，只留前两类 + 你自己标的**关注标签**。

为什么：军训备注里记的是「膝盖受伤、请假」这类**身体 / 请假**的事，确实值得跟进，
但它和"学业预警"不是一回事，不该由一列旧导出字段**自动**判定 —— 该由你自己标。
所以这类学生，请在学生详情页用**关注标签**手动标一下。

> ⚠️ **你会看到的变化**：「需重点关注」的**人数会变少**（少了那些只有军训备注的人）；
> 仪表盘「关注提醒」里原来那条「军训需关注」也一并去掉了。
> 军训备注本身**没有删** —— 学生详情页「入学与住宿」里照样看得到、也能编辑。

### 🔧 内部加固（不影响你怎么用）

- 把「按列合并」的四条铁律收到一处实现 —— 原先有**两份复制体**，并且已经各自演化出了差异。
- 清掉一个从来没执行过的占位函数（它只会显示"数据总览构建中…"，被后面的真实现盖住了）。
- 回归测试补了 17 条**跨路径**断言，专门盯「同一条规则在每条路径上都要生效」。

### ⬆️ 从旧版升级

直接覆盖安装、或换用新版绿色版即可 —— 数据存在本机应用数据目录里（桌面版每次保存都会自动镜像一份
`workstation-data.json`），**升级不会丢数据**。在「系统设置 → 数据管理」底部可以看到「自动保护」的当前状态
（桌面版应为**已开启**）；想手动再固化一份，点那一行的「立即固化一份」。

### 🖥 运行环境

- **Windows**：Windows 10/11 64 位，需要 Microsoft Edge WebView2 运行时
  （Win11 与多数装过 Edge 的 Win10 已有；安装器内嵌引导程序，缺的机器会自动装）。
- **macOS**：macOS 10.15 及以上，Intel 与 Apple 芯片都可以；系统自带网页运行时，不需要额外安装东西。
- 两个平台都**不需要** Node.js / Rust / .NET —— 那些只在重新出包时才用得到。

详细用法见仓库内的 `中南大学生工作台-用户使用手册.docx`。
