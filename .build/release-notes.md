## v2.1.0 —— AI 助理：新增「学工工作助理」· 金句框不再忽长忽短

面向高校辅导员的**本机学生工作台**：把系统里导出的学生信息表 + 成绩单放进来，自动拼出每个人的画像、成绩、宿舍与预警。**数据只存本机，全程不联网、不上传服务器。**

> 本版**没有数据格式变更**，升级不动你已有的数据。Windows 与 macOS 两个平台都有新包。

### 🤖 「AI 辅导员」改名「AI 助理」，并新增第三个入口

现在这一页收三个企业微信入口，三张二维码并列（窄屏自动 2 列 / 手机 1 列）：

| 入口 | 谁用 | 适合问 |
| --- | --- | --- |
| **学工工作助理**（本版新增） | **辅导员专用** | **你工作上的任何问题**都可以问它 —— 制度口径、流程节点、材料怎么写、话术怎么讲；答复口吻更专业、更讲依据 |
| **AI 辅导员 · 鹿晓南** | 学生可自助 | 请假销假与晚归报备、奖助学金与困难认定、考试缓考与学籍等制度流程类问题 |
| **综合评定答疑机器人** | 学生可自助 | 加分细则、材料要求、时间节点等综合测评与评奖评优口径 |

后两个仍是学生可自助的答疑入口（可以拉进自己的班级群）；每张码下面都有「复制链接」。

> 为什么改名：这一页现在收的是三个入口、其中一个还是辅导员自己用的，
> 再叫「AI 辅导员」容易让人以为都是给学生用的。

### 📏 顶栏金句框不再忽长忽短

顶栏那 60 条育人金句长短差得比较多（最长 40 字、最短 12 字）。原来那个框是按文字长度自适应的，
**换一句、框就变一次长度**，看着很跳。现在按最长的那句**固定了宽度**：短语录留白，框本身不再变。

（过程中还顺手修掉一个自己引入的问题：把框定宽后顶栏装不下，用户头像那塊被挤出屏幕外 ——
已经改成"窗口窄了框可以让位"，所以不会再出现横向滚动条。）

### ⬆️ 从旧版升级

直接覆盖安装、或换用新版绿色版即可 —— 数据存在本机应用数据目录里（桌面版每次保存都会自动镜像一份
`workstation-data.json`），**升级不会丢数据**。在「系统设置 → 数据管理」底部可以看到「自动保护」的当前状态
（桌面版应为**已开启**）；想手动再固化一份，点那一行的「立即固化一份」。

### 🖥 运行环境

- **Windows**：Windows 10/11 64 位，需要 Microsoft Edge WebView2 运行时
  （Win11 与多数装过 Edge 的 Win10 已有；安装器内嵌引导程序，缺的机器会自动装）。
- **macOS**：macOS 10.15 及以上，Intel 与 Apple 芯片都可以；系统自带网页运行时，不需要额外安装东西。
- 两个平台都**不需要** Node.js / Rust / .NET —— 那些只在重新出包时才用得到。

详细用法见仓库内的 `中南大学生工作台-用户使用手册.docx`。
