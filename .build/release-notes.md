## v2.2.0 —— 新增「奖学金评选」+ 密码改成手动锁 + 周次可以手动校正

面向高校辅导员的**本机学生工作台**：把系统里导出的学生信息表 + 成绩单放进来，自动拼出每个人的画像、成绩、宿舍与预警。**数据只存本机，全程不联网、不上传服务器。**

> 本版**没有数据格式变更**，原来导进去的学生名册、成绩单、宿舍数据都原样保留。
> 奖学金评选是**新模块**，第一次用需要重新导入两张表。Windows 与 macOS 两个平台都有新包。

---

### 🆕 奖学金评选（全新模块）

把「智慧学工」导出的两张表丢进来，就能按综合测评排序、逐个奖项定人选。

**一个学生就是一行。** 他报了几个奖项就在「志愿」格里并列显示几个 —— 不会像有的表那样
把一个人拆成五六行，重复到没法看。

**表从哪导**（导入弹层里也有写）：

| 要导的 | 路径 |
|---|---|
| 申报情况 | 智慧学工 → **奖学金** → 志愿申报情况 → 导出 → **自定义导出** → 字段**全选**后导出 |
| 综合测评分数 | 智慧学工 → **综合测评** → 测评审核 → 导出 → **自定义导出** → 字段**全选**后导出 |

**能按哪些分数排**：综合测评、知识水平评价、B1~B5 七列，点列名就排。
筛到某个奖项会自动切到它该看的那列 —— 评「科研创新奖学金」自动按 B1 排，评「文体佳绩」按 B3 排。

> ⚠️ 有一处特意要说清楚：综合测评表里的「**审核状态：已通过**」是**综合测评材料**的审核状态
> （材料在系统里审过了），**不是奖学金的评定结果**。所以这一列我们不导入、也不显示 ——
> 评定结果由你在页面上「拟定 → 复核确认」产生。

**拟定流程**（防"点一个消失一个，影响判断"）：

1. 点「拟定」只是**打标记** —— 那行变色、名字后挂个角标，**人还留在列表里**；
2. 顶部浮出「复核确认 (N)」条，可以先「查看清单」逐个核对，也能「全部取消」；
3. 核对无误点「确认」，才**正式进入拟定名单**。

**批量拟定**：列表每行前面有复选框（表头可全选），勾上多人 →「批量拟定」→ 选一个奖项，
一次给所有人打标记，之后照样走「复核确认」统一生效。

**不兼得规则**：除单项奖学金（文体佳绩 / 社会实践 / 社会工作 / 科研创新）外，
**各奖项不兼得** —— 一个人定了国家奖学金，就自动从其他综合类奖项的候选里剔掉；
单项奖不受影响，可以叠加。

**名额**：奖项筛选条右边「名额设置」，一个区域里把 11 个奖项的名额一次录完。
留空 = 不限，**填 0 = 这个奖项今年没有名额**。超了只标红提示，不拦你（实际评选常有递补）。

**按批次隔离**：按申报表里的「批次」列自动归档，顶部下拉切换。
今年的数据和明年的数据各归各的，导出的文件名也带批次，互不串。

### 🔓 密码：从"开机就锁"改成"想锁才锁"

原先每次打开都要输密码，忘了就进不去。现在：

- **启动直接进工作台**，不再拦着你设密码 / 输密码；
- 顶栏多了一把**锁图标**，想锁的时候点一下才锁（**个人中心 → 安全**里也有一处入口）；
- **解锁码 `8838` 任何时候都能解开** —— 万一忘了自己设的密码，不会被关在外面。
  （数据本来就只存在你自己的电脑上、不联网，这把锁防的是路过的人顺手翻看，不是防黑客。）

### 📅 周次：算不准就手动掰一次，之后自动往后走

国庆中秋放假、临时停课、运动会冲课……都可能让"按开学日算的周数"跟学校实际对不上。

不用去配什么假期规则（每年都不一样，猜了也会错）。直接**点顶栏的周数**，
把本周改成正确的周数就行 —— 系统记下"这一周的周一 = 第 N 周"，**下周起自动 +1**。
以后再遇到变化，**再改一次**就行，周数永远是准的。

> 顺带把默认学期信息按中南财大 2026-2027 第一学期校历更新了：**9 月 7 日（周一）开学，共 20 周**。

### 🎨 界面调整

- 奖学金页的概览压成一行小字（原来单独占一整张卡），名额区从大表格改成紧凑网格，省一屏；
- 「全部清空」和「收起」分到页面两端，且清空加了**二次确认** —— 之前两个挨在一起，手一抖就清空了；
- 奖学金列表**去掉班级、加上专业**；**操作列挪到「志愿」前面**（志愿那列很宽，按钮放最后会被挤到屏幕外）；
- 暗黑模式下拟定行改成主题自适应配色（原先是硬编码浅黄底 + 浅色字，几乎看不清，实测对比度只有 1.14:1），
  现在三套主题都达 AA 标准。

### 🔧 内部加固（不影响你怎么用）

- 奖学金成绩按**评选批次分桶**存储；老存档（早期"一志愿一行"的结构）自动聚合成"一学生一行"，一条不丢；
- 修一个会**把成绩清空**的隐患（判断普通对象写成了 `!Array.isArray(...)`，导致每次进页面都把成绩桶冲成空的）；
- 回归闸门新增周次校准专项（30 条），奖学金端到端冒烟 117 条。

### ⬆️ 从旧版升级

直接覆盖安装、或换用新版绿色版即可 —— 数据存在本机应用数据目录里（桌面版每次保存都会自动镜像一份
`workstation-data.json`），**升级不会丢数据**。在「系统设置 → 数据管理」底部可以看到「自动保护」的当前状态
（桌面版应为**已开启**）；想手动再固化一份，点那一行的「立即固化一份」。

> 提醒：启动密码规则变了 —— 升级后**直接进工作台**，不再每次要密码。
> 想锁的时候点顶栏的锁图标，解锁码 `8838`。

### 🖥 运行环境

- **Windows**：Windows 10/11 64 位，需要 Microsoft Edge WebView2 运行时
  （Win11 与多数装过 Edge 的 Win10 已有；安装器内嵌引导程序，缺的机器会自动装）。
- **macOS**：macOS 10.15 及以上，Intel 与 Apple 芯片都可以；系统自带网页运行时，不需要额外安装东西。
- 两个平台都**不需要** Node.js / Rust / .NET —— 那些只在重新出包时才用得到。

详细用法见仓库内的 `中南大学生工作台-用户使用手册.docx`。
