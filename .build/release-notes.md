## v2.4.4

面向高校辅导员的**本机**学生工作台。把教务 / 学工系统导出的表放进来，自动拼出学生画像、
成绩、宿舍与学业预警，并有一套能真正干活的**奖学金评选**流程。

**数据只存本机，全程不联网、不上传服务器。**

### 这一版改了什么

**奖学金评选：批量拟定的操作流程重做**

原来的毛病：在「全部候选人」里勾选学生，批量条只给出「取消拟定 / 取消选择」两个动作，
想把人定给某个奖，反而要先点奖项卡片筛进来 —— 流程顺序是反的，而且「取消拟定」
读起来像「取消刚才的操作」，容易误解。

现在的做法：

- 批量条里直接给出 **「拟定为 [奖项下拉]」+「拟定」**，「选人 → 选奖项 → 拟定」
  在一个地方完成，不必先筛进某个奖
- 正在看某个奖时，下拉**自动默认到它**，老用法一步也没多
- 「取消拟定」改为 **「清除拟定（N 人）」**，而且**只在选中的人真有拟定时才出现**；
  拟定本来就是 0 的时候它不会再来干扰
- 「取消选择」降为文字按钮，让主操作「拟定」站住
- 就地刷新批量条时**保留你已经选好的奖项**，不会因为多勾一个人就被重置

> 如果你是从 v2.4.2 或更早升上来的，v2.4.3 的这些也在里面：
> 可配置的**剔除规则**（无总成绩 / 二学位 / 第二学位 / 手动名单）、**列设置**
> （列的显隐与拖拽排序）、勾选不再跳回顶部、单独清除某个奖项的拟定、
> 以及奖学金页面的整体重设计（横向进度卡 + 进度区可收起）。
