中南大学生工作台 v1.0

推荐安装
---------
双击“中南大学生工作台-安装程序.exe”，按向导完成安装即可。
默认按当前 Windows 用户安装，不需要管理员权限；安装完成后可从桌面或开始菜单启动。

其他文件
---------
“中南大学生工作台-单位部署.msi”适合学校统一部署，通常需要管理员权限。
“中南大学生工作台-绿色版.exe”无需安装，复制到任意文件夹后双击即可运行。

运行环境
---------
Windows 10/11 64 位。
程序不需要安装 Node.js、Rust 或 .NET。
电脑需要 Microsoft Edge WebView2 运行时。Windows 11 和大多数安装过 Edge 的 Windows 10 电脑已经具备；安装器已经内嵌 WebView2 引导程序，缺少运行时的电脑会在安装过程中尝试自动安装。完全离线的电脑仍需提前准备 WebView2 离线运行时。

数据与导出
----------
工作数据保存在本机，不上传服务器。
桌面版每次保存都会同时镜像一份到磁盘文件：
    %APPDATA%\cn.edu.zuel.studentworkstation\workstation-data.json
清理浏览器缓存、重置 WebView 或重装程序，下次打开都会自动从这里恢复；导入历史快照也放在同一目录。
导出的 CSV 与备份文件默认保存到 Windows“下载”文件夹；「系统设置 → 数据管理 → 打开备份文件夹」可一键打开该目录。
宿舍看板导出的“宿舍查寝卫生打分表”同样落在“下载”文件夹，并会自动用默认浏览器打开，按 Ctrl+P 即可打印（打印设置里选“横向”）。
卸载软件不会自动删除本地工作数据；如需迁移或清理，请先备份后再处理。

托盘与开机启动
--------------
点窗口右上角“×”默认不退出，程序缩到任务栏右下角的系统托盘继续运行；左键单击托盘图标唤回窗口，右键菜单里有“退出”。
要改成点“×”直接退出：系统设置 → 常驻与开机启动 → 最小化到系统托盘 → 关。
开机自动启动可在同一处开启；开启后开机登录时安静启动在托盘里，不弹窗。该设置只写入当前用户的“启动”目录，不需要管理员权限，随时可关。
