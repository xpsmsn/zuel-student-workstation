ZUEL 辅导员工作台 v2.5.0

本版本提供 Windows 安装包（三种形式）与 macOS 安装包，按你的场景选一个即可。

    Windows：推荐安装
    -----------------
    双击“ZUEL 辅导员工作台-v2.5.0-安装程序.exe”，按向导完成安装。
    默认按当前 Windows 用户安装，不需要管理员权限；装完可从桌面或开始菜单启动。

    Windows：单位统一部署
    -------------------
    “ZUEL 辅导员工作台-v2.5.0-单位部署.msi”适合学校信息办统一推送，通常需要管理员权限。

    Windows：免安装
    -----------------
    “ZUEL 辅导员工作台-v2.5.0-绿色版.exe”无需安装，复制到任意文件夹（路径尽量别含中文与空格）后双击即可。

    macOS
    -----
    打开“ZUEL 辅导员工作台-v2.5.0-macOS.dmg”，把程序拖进「应用程序」。
    Intel 芯片与 Apple 芯片（M 系列）通用。
    第一次打开若被系统拦截：右键点图标 →「打开」放行一次即可（本版本用临时签名）。


这一版做了什么
--------------
· 文字看得清了：亮色 / 暗色 / 护眼三套主题的二级三级文字、警示色、主按钮白字
  全部达到 WCAG AA（4.5:1 以上）。原先三级文字只有 2.73:1。
· 键盘能走完整个工作台：每个输入框、按钮、表格行都有看得见的焦点环；
  左侧模块、表格行、统计卡 Tab 能到、Enter 与空格能激活。
· 弹窗规范了：确认框焦点留在框内、Esc 可关、关掉焦点回到原按钮，
  默认选中「取消」而不是右上角 ×。
· 撤销条修好了：鼠标移上去不再右移；删除学生 / 批量删除 / 删批次 / 清理评选数据
  不会再同时冒出两条提示互相遮挡。
· 字号成体系：34 档字号收成 4 档正文（24 / 18 / 15 / 13）+ 图标 32；字重只剩 400 / 600；
  圆角只剩 0 / 6 / 12 / 50%。
· 多级排序可逐级取消（点某一级的 × 只撤这一级，表头显示 ↑① ↓②）；
  窄屏卡片模式补了「全选 + 排序」工具条；横向滚动时勾选框首列固定。
· 可点击提示不再只有鼠标悬停才出现；触控命中区补到 44×44。
· 顺手修了两个“看着正常、其实早没生效”的问题：切筛选后焦点其实会掉回页面顶部；
  重绘瞬间按下标还原焦点会指偏。


提醒
--------
· 数据只保存在你自己的电脑上，全程不联网、不上传服务器。
· 换电脑或重装系统前，记得在「⋯ → 导出备份」里导一份数据文件。
· 覆盖安装即可升级，本机数据不丢。装之前请先从托盘彻底退出旧版本
  （右键托盘图标 →「退出」，不是关窗口）。


运行环境
---------
· Windows 10 / 11（64 位），或 macOS 10.15 及以上（Intel / Apple 芯片通用）
· 程序自带界面运行环境，无需另外安装任何东西
