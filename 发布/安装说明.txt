中南大学生工作台 v1.9.8

本版本同时提供 Windows 与 macOS 安装包，按你的电脑选一个即可。


Windows：推荐安装
-----------------
双击“中南大学生工作台-v1.9.8-安装程序.exe”，按向导完成安装即可。
默认按当前 Windows 用户安装，不需要管理员权限；安装完成后可从桌面或开始菜单启动。

Windows：其他文件
-----------------
“中南大学生工作台-v1.9.8-单位部署.msi”适合学校统一部署，通常需要管理员权限。
“中南大学生工作台-v1.9.8-绿色版.exe”无需安装，复制到任意文件夹后双击即可运行。


macOS：安装
-----------
双击“中南大学生工作台-v1.9.5-macOS.dmg”（注：Mac 包当前为 v1.9.5，v1.9.6 的 Mac 版待下次构建；两版功能一致，本版新增功能仅在 Windows 版），把里面的程序拖进左侧的“应用程序”文件夹。
同一个安装包同时支持 Intel 芯片与 Apple 芯片（M 系列），不用挑。

　⚠️ 第一次打开请用「右键 → 打开」放行一次
　　macOS 会提示“无法打开，因为 Apple 无法检查是否包含恶意软件”。这不是文件损坏：
　　本软件没有购买苹果开发者账号（每年 99 美元），安装包做的是临时签名。
　　放行办法：在“应用程序”里右键点它 → 选“打开” → 再点一次“打开”。只需放行一次，以后双击即可。
　　如果右键菜单里没有“打开”，去「系统设置 → 隐私与安全性」，页面下方会有“仍要打开”按钮。


运行环境
---------
Windows：Windows 10/11 64 位。
程序不需要安装 Node.js、Rust 或 .NET。
电脑需要 Microsoft Edge WebView2 运行时。Windows 11 和大多数安装过 Edge 的 Windows 10 电脑已经具备；安装器已经内嵌 WebView2 引导程序，缺少运行时的电脑会在安装过程中尝试自动安装。完全离线的电脑仍需提前准备 WebView2 离线运行时。

macOS：macOS 10.15（Catalina）及以上，Intel 与 Apple 芯片均可。
Mac 系统自带网页运行时，不需要额外安装任何东西。


数据与导出
----------
工作数据保存在本机，不上传服务器。
桌面版每次保存都会同时镜像一份到磁盘文件：

    Windows:  %APPDATA%\cn.edu.zuel.studentworkstation\workstation-data.json
    macOS:    ~/Library/Application Support/cn.edu.zuel.studentworkstation/workstation-data.json

清理浏览器缓存、重置网页数据或重装程序，下次打开都会自动从这里恢复；导入历史快照也放在同一目录。
导出的 CSV 与备份文件默认保存到当前用户的“下载”文件夹；「系统设置 → 数据管理 → 打开备份文件夹」可一键打开该目录。
宿舍看板导出的“宿舍查寝卫生打分表”同样落在“下载”文件夹，并会自动用默认浏览器打开，按 Ctrl+P（macOS 上是 ⌘+P）即可打印（打印设置里选“横向”）。
卸载软件不会自动删除本地工作数据；如需迁移或清理，请先备份后再处理。


托盘与开机启动
--------------
点窗口右上角“×”默认不退出，程序缩到系统托盘继续运行：
Windows 在任务栏右下角，macOS 在屏幕右上角的菜单栏。
点一下托盘 / 菜单栏图标唤回窗口，右键菜单里有“退出”。
要改成点“×”直接退出：系统设置 → 常驻与开机启动 → 最小化到系统托盘 → 关。
开机自动启动可在同一处开启；开启后开机登录时安静启动在后台，不弹窗。该设置只写当前用户自己的
设置（Windows 写“启动”目录、macOS 写 LaunchAgent），不需要管理员权限，随时可关。
程序只允许运行一个：已经在后台时，再次双击图标/快捷方式不会开出第二个窗口，而是把原来那个窗口叫回前台。

注意（macOS）：在 Mac 上“⌘+Q”是直接退出，这是 Mac 的通用习惯，不走上面那个“缩到托盘”的开关。
想让它在后台常驻，请点窗口左上角的红色按钮。
